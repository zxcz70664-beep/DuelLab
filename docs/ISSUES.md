# V0.1 已知问题

1. 所有操作仅为前端演示，没有规则引擎校验。
2. 状态仅保存在浏览器内存，刷新即重置。
3. 对手场面没有实际操作逻辑。
4. 抽卡使用占位卡，不是真正的洗切卡组。
5. 无连锁、优先权、诱发效果时点和裁定。
6. 无超量素材、控制权、卡牌状态及真实区域移动模型。
7. 无登录、房间、WebSocket、数据库及玩家权限隔离。
8. 移动端布局尚未完整验收。
9. 使用文字占位卡面，没有引入未经授权的官方卡图。

## 试用反馈重点
- 场地布局是否符合操作习惯？
- 手牌大小与横向滚动是否合适？
- 墓地、除外区、额外卡组是否需要独立查看面板？
- 连锁队列是否应固定在场地中央？
- 卡牌详情是否需要完整显示效果文本和①②③编号？
