# V0.2 已知问题与后续工作

## V0.2 当前限制
- 房间和状态仅存在 Node.js 进程内存，重启后丢失。
- 当前状态广播包含双方手牌数量，不包含手牌内容；未来必须实现仅向所属玩家发送手牌明细。
- 当前在线测试动作不校验回合控制权，任何持有房间令牌的玩家都可调整自己的生命值、推进阶段或结束回合。
- 没有动作序号/幂等处理、速率限制、断线宽限期和持久化。
- WebSocket 令牌存储在当前浏览器 sessionStorage；同一浏览器标签页会话刷新可恢复，关闭会话后可能无法恢复。
- 没有真实 OCG 规则、卡牌脚本或效果结算。

## 下一步建议
1. 在独立分支部署并完成两浏览器真实联机测试。
2. 加入服务端动作校验、回合控制权和状态版本号。
3. 设计私有手牌与公开场面分离的数据结构。
4. 评估持久化存储和实例重启恢复。
5. 完成后再接入 OCGCore；不把当前演示动作包装成正式规则。
