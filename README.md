# DuelLab

DuelLab 是私人网页端游戏王决斗模拟器项目，当前开发方向为单人玩家 VS AI。

## 当前开发分支
- 分支：`singleplayer-v0.2`
- 当前里程碑：单人工作台与本地卡组管理基础
- 线上 V0.1 保持不变；本分支尚未部署。

## 当前已实现
- 响应式单人模式工作台页面
- 页面导航：首页、我的卡组、卡牌资料库、设置
- 本地卡组创建、重命名、删除
- 手动添加/移除卡牌名称条目，区分主卡组与额外卡组
- 使用浏览器 Local Storage 保存卡组
- 卡组 JSON 导入和导出

## 明确未实现
- OCGCore / WASM 规则引擎
- 官方 OCG 卡牌数据库和效果脚本
- 卡组合法性与日本 OCG 禁限卡表校验
- 真实召唤、连锁、效果处理、素材和区域移动
- AI 决策与玩家 VS AI 对局
- 云端同步、账号和双人在线

## 使用说明
此分支目前尚未部署。卡组保存在当前浏览器本地，清理浏览器数据可能导致数据丢失。请定期导出 JSON 备份。

## 部署
项目沿用根目录 Dockerfile 和 Node.js 静态服务入口。只有通过阶段验收后才考虑部署，不覆盖现有 V0.1。
